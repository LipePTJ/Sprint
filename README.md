# Sprint - Consumo de API

Atividade de **Frontend - JavaScript** desenvolvida para praticar o consumo de APIs.

## Sobre o projeto

O projeto consiste em uma aplicação web de busca de Pokémon, utilizando JavaScript para realizar o consumo de uma API e apresentar os dados na página.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* API de Pokémon

## Estrutura do projeto

```text
POKEDEX/
├── css/
│   └── style.css
├── images/
│   └── icon/
│       └── Pokebola.png
├── js/
│   └── script.js
└── index.html
```

## Funcionalidades

* Busca de Pokémon.
* Consumo de dados através de uma API.
* Exibição das informações dos Pokémon.
* Interface desenvolvida com HTML e CSS.
* Manipulação dos dados utilizando JavaScript.
